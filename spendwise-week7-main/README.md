## 1. Project Description

SpendWise is a modern, responsive personal budget and expense tracking application. It helps users manage their monthly budgets, record daily expenses, monitor spending and calculate their remaining balance.

The application provides a simple and professional dashboard for managing personal finances.

## 2. Project Objectives

- Develop a professional budget management application.
- Allow users to set and update monthly budgets.
- Record and manage daily expenses.
- Calculate total expenses automatically.
- Display the remaining budget.
- Save information using browser Local Storage.
- Deploy the application online using Netlify.
- Manage project files using GitHub.

## 3. Key Features

- Monthly budget management.
- Add and delete expenses.
- Expense categories.
- Automatic expense calculations.
- Remaining balance tracking.
- Budget progress indicator.
- Expense search and filtering.
- CSV expense export.
- Data persistence using Local Storage.
- Responsive dashboard design.

## 8. Deployment Process Summary

The project was deployed using GitHub and Netlify.

Deployment steps:

1. Prepared and organized the project files.
2. Created a public GitHub repository.
3. Uploaded the SpendWise project files to GitHub.
4. Created a Netlify account.
5. Connected Netlify to the GitHub account.
6. Selected the spendwise-week7 repository.
7. Configured the deployment settings.
8. Deployed the website successfully.
9. Tested the published website.

## 9. Challenges Encountered During Deployment
